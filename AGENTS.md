# UniSage Web

Frontend for UniSage, an academic knowledge and student-support platform. React 19 + Vite, English UI/codebase.

Project conventions live in `.claude/rules/` as topic-scoped files (commands, architecture,
conventions, styling, UI rules, RBAC/permissions, git workflow, environment, ADR policy, and the
pre-commit/PR checklist) — Claude Code loads them automatically, either at session start or when a
matching file enters context.
